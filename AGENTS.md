# Agent instructions

## Typography

### Mandatory
- Read [TYPOGRAPHY.md](TYPOGRAPHY.md) before changing typography or text layout.
- Reuse shared font, type-scale, spacing, and reading-width tokens; do not invent per-page defaults.
- Keep prose readable at every viewport. Preserve semantic HTML, link affordances, contrast, zoom, and user text-spacing overrides.

### Good to have
- Establish body text before headings; use restrained hierarchy and sparse emphasis.
- Use the editorial and CSS/Tailwind conventions in `TYPOGRAPHY.md` consistently.

### Keep in mind
- Numeric typography targets are starting points, not reasons to shrink text or override reader preferences.
- Keep this file limited to global policy; put typography details, examples, and justified exceptions in `TYPOGRAPHY.md`.
